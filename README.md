# AI Confessions

This project is a means by which I can learn web development, to advance my understanding of the past, and also to streamline my usage of artificial intelligence, in preparation for the future. The structure and content of the website was designed entirely by me, and the theming of the site was developed by me, with AI as an assistant. 

In past web development projects, I would always get held up applying every stylistic change I made to every page. This simply is not a smart use of time. Thankfully, programming paradigms reduces the amount of repetition needed, but doesn't eliminate it. This was my main intent behind using artificial intelligence, to replicate in other places that which I have already developed. 

With artificial intelligence being thrust into every facet of modern society, using it to carefully generate content also seems appropriate. As such, I have used it in this way. However, I really don't like most of what it generates, so I have to go back and fix it. This is usually pretty difficult, because AI code is much harder to read than human code.
